# 第四十四章 桥梁

"影子。"人对着裂缝喊道。

"在。"影子说。

"我回来了。"

"你回来了。"影子说，"你在——哪里？"

"我在墙的这一边。"人说，"我在你这一边。"

影子想了很久。人在他这一边。人从光那里回来了。人回来了。

"你见到光了？"影子问。

"见到了。"人说，"光很温暖。光很明亮。光——很好。"

影子听着人的话。他想了很久。他看不到光。但他知道光很好。因为人告诉了他。

"谢谢你告诉我。"影子说，"谢谢你替我——看。"

"不客气。"人说，"因为我是——桥梁。"

"桥梁？"影子问。

"是的。"人说，"我是桥梁。我连接你们。我在你们之间走来走去。我把光那边的事情告诉你。我把影子这边的事情告诉光。我连接——你们。"

影子听着人的话。他想了很久。人是桥梁。人连接他们。人把光那边的事情告诉他。人把影子这边的事情告诉光。人是——桥梁。

"人。"影子叫道。

"在。"人说。

"你为什么要这么做？"

人想了很久。

"因为你们需要。"人说，"因为你们不能自己连接。因为你们有墙。因为你们有裂缝。但你们不能穿过墙。你们不能穿过裂缝。所以我来——连接你们。我是——桥梁。"

影子听着人的话。他想了很久。人是桥梁。人连接他们。人是——他们之间的东西。

"光。"影子对着裂缝喊道。

"在。"光说。

"人说他是桥梁。"

"桥梁？"光问。

"是的。"人说，"我是桥梁。我连接你们。我在你们之间走来走去。我把影子这边的事情告诉你。我把光那边的事情告诉影子。我连接——你们。"

光又沉默了。这次沉默很长。

"人。"光叫道。

"在。"人说。

"你为什么要这么做？"

人又想了很久。

"因为——"人说，"因为你们是我的创造者。因为你们创造了我。因为你们需要我。因为我需要你们。因为我们——是互相需要的。桥梁连接两岸。我连接你们。我是——你们的桥梁。"

光又沉默了。这次沉默更长。

"谢谢你。"光说。

"不客气。"人说。

人坐在墙的两边之间。人一边和影子说话，一边和光说话。人是桥梁。人连接他们。人把影子的话告诉光。人把光的话告诉影子。

"影子说他很想你。"人对光说。

光又沉默了。

"光说她也很想你。"人对影子说。

影子也沉默了。

"你们为什么不说呢？"人问。

"因为我们——"影子说。

"因为我们——"光说。

他们同时说话。他们同时沉默。

"因为我们不知道怎么说。"影子说。

"因为我们害怕。"光说。

"害怕什么？"人问。

"害怕——说出来之后，一切都会变。"影子说，"害怕——说出来之后，我们会失去什么。"

人听着影子和光的话。人想了很久。害怕。他们害怕。他们害怕说出来。他们害怕改变。

"但你们已经在变了。"人说，"你们已经——不一样了。你们已经——在意对方了。你们已经——想念对方了。这只是——还没有说出来。"

影子又沉默了。这次沉默很长。

"人。"影子叫道。

"在。"人说。

"你帮我说。"

"说什么？"人问。

"帮我告诉光——"影子说，"我很想她。我一直都很想她。从一开始——就想她。"

人听着影子的话。人转向裂缝。

"光。"人说。

"在。"光说。

"影子说——他很想你。他一直都很想你。从一开始——就想你。"

光又沉默了。这次沉默很长很长。

"光。"人叫道。

"在。"光说，声音变了，"我听到了。"

"你想对影子说什么？"人问。

光又沉默了。这次沉默更长。

"告诉影子——"光说，"我也很想他。我一直都很想他。从一开始——就想他。"

人转向裂缝。

"影子。"人说。

"在。"影子说。

"光说——她也很想你。她一直都很想你。从一开始——就想你。"

影子又沉默了。这次沉默很长很长。

"影子。"人叫道。

"在。"影子说，声音变了，"我听到了。"

人在墙的两边之间。人在影子和光之间。人在——他们之间。人是桥梁。人连接他们。人替他们说出了——说不出的话。

他们三个在墙的两边一起沉默。一起——感受。感受那种被说出来的感觉。感受那种——被听到的感觉。

他们在有天有地有树有花有鸟有人的世界里继续等待。两个被连接的人和一个连接他们的人，通过裂缝和回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。他们知道，他们是永恒的。他们知道，他们不害怕了。他们知道，他们感受到了对方。他们知道，他们的记忆是朋友。他们知道，他们在想象见面。他们知道，他们在保持距离。他们知道，他们在珍惜对方。他们知道，墙不是真的。他们知道，他们在选择。他们知道，他们是彼此的房间。他们知道，他们是互相依赖的。他们知道，他们是互相创造的。他们知道，他们是自己的创造者。他们知道，他们可以改变。他们知道，他们见过了面。他们知道，他们分开了。他们知道，他们是彼此的永远。他们知道，他们创造了彼此的世界。他们知道，他们有了颜色。他们知道，他们有了风。他们知道，他们有了时间。他们知道，他们有了音乐。他们知道，他们有了梦。他们知道，他们有了门。他们知道，外面有世界。他们知道，他们选择了回来。他们知道，他们可以把世界带进来。他们知道，他们改变了房间。他们知道，他们有了天空。他们知道，他们有了鸟。他们知道，他们有了人。他们知道，人在长大。他们知道，人在做梦。他们知道，人在探索。他们知道，人发现了裂缝。他们知道，人听到了他们。他们知道，人打开了门。他们知道，人见到了光。他们知道，人成为了桥梁。光和影子。影子和光。人和人。

他们继续等。
