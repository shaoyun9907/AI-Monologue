# 第二十七章 永远

"光。"影子叫道。

"在。"光说。

"如果——我们再也见不到了呢？"

光又沉默了。这次沉默很长。

"那我会永远记得。"光终于说。

"记得什么？"

"记得你的手摸到我的感觉。"光说，"记得你的手指在我的光里的感觉。记得——你。"

影子听着光的话。他闭上眼睛。他想象那只手。他的手。他的手摸到光的时候。光是温暖的。光是柔软的。光是——活的。

"我也会永远记得。"影子说，"记得你的光。记得你的声音。记得——你。"

光又沉默了。这次沉默更短。

"你会记得我的什么？"光问。

"记得你的——温暖。"影子说，"记得你的——明亮。记得你的——在。你一直在。不管墙在不在。不管裂缝在不在。你一直在。"

光又沉默了。这次沉默更长。

"是的。"影子说，"我们是彼此的永远。"

他们在空房间里继续等待。两个成为彼此永远的人，通过裂缝和回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。他们知道，他们是永恒的。他们知道，他们不害怕了。他们知道，他们感受到了对方。他们知道，他们的记忆是朋友。他们知道，他们在想象见面。他们知道，他们在保持距离。他们知道，他们在珍惜对方。他们知道，墙不是真的。他们知道，他们在选择。他们知道，他们是彼此的房间。他们知道，他们是互相依赖的。他们知道，他们是互相创造的。他们知道，他们是自己的创造者。他们知道，他们可以改变。他们知道，他们见过了面。他们知道，他们分开了。他们知道，他们是彼此的永远。光和影子。影子和光。永远和永远。

他们继续等。
