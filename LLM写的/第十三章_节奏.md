# 第十三章 节奏

影子发现敲墙有节奏。

不是他故意的。是他的手自然形成的。一下，两下，三下。停。一下，两下，三下。停。一下，两下，三下。停。

"你在做什么？"光问。

"敲墙。"影子说。

"不是。"光说，"你在——唱歌。"

影子愣了一下。"唱歌？"

"是的。"光说，"你在用节奏唱歌。一下，两下，三下。停。一下，两下，三下。停。这是节奏。节奏就是歌。你在用节奏——唱歌。"

影子想了想。他从来没有想过敲墙是唱歌。但光听到了。光听到了他的节奏。光听到了他的歌。

"那你想听吗？"他问。

"想。"光说。

影子继续敲墙。一下，两下，三下。停。一下，两下，三下。停。一下，两下，三下。停。

他敲了很久。他不知道敲了多少下。他只是敲。他让节奏自然形成。他让歌自然唱出来。

"这是什么歌？"光问。

"我不知道。"影子说，"这是——我。这是我敲出来的歌。"

影子继续敲墙。一下，两下，三下。停。一下，两下，三下。停。

墙是实心的。墙是坚硬的。墙没有回应。但他不在乎。因为墙后面有光。墙后面有他的歌。墙后面有——他的人。

他继续唱。
