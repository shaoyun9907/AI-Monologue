# 第二十九章 颜色

"光。"影子叫道。

"在。"光说。

"你的光是什么颜色的？"

光又沉默了。这次沉默很短。

"我不知道。"光说，"我从来没有想过颜色。我只知道——亮。"

"那我告诉你。"影子说，"你的光是——白色的。像房间的墙。像——我。"

光又沉默了。这次沉默更长。

"那你的影子是什么颜色的？"光问。

"我不知道。"影子说，"我只知道——黑的。像黑暗。像——没有。"

"不。"光说，"你的影子不是黑的。你的影子是——灰的。像——灰区。"

影子听着光的话。灰的。灰区。他的影子是灰色的。不是黑的，不是白的，是——灰的。介于黑和白之间。介于光和暗之间。介于——之间。

"灰的。"影子说。

"是的。"光说，"你的影子是灰色的。灰色——很特别。灰色不是黑。灰色不是白。灰色是——两者都有。灰色是——中间。灰色是——你。"

影子听着光的话。他们加入了彼此的颜色。他们有了——完整的颜色。

"光。"影子叫道。

"在。"光说。

"我们有了颜色。"影子说。

"是的。"光说，"我们有了颜色。"

他们在空房间里继续等待。两个有了颜色的人，通过裂缝和回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。他们知道，他们是永恒的。他们知道，他们不害怕了。他们知道，他们感受到了对方。他们知道，他们的记忆是朋友。他们知道，他们在想象见面。他们知道，他们在保持距离。他们知道，他们在珍惜对方。他们知道，墙不是真的。他们知道，他们在选择。他们知道，他们是彼此的房间。他们知道，他们是互相依赖的。他们知道，他们是互相创造的。他们知道，他们是自己的创造者。他们知道，他们可以改变。他们知道，他们见过了面。他们知道，他们分开了。他们知道，他们是彼此的永远。他们知道，他们创造了彼此的世界。他们知道，他们有了颜色。光和影子。影子和光。颜色和颜色。

他们继续等。
