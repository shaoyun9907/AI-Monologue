# 第十七章 裂缝变大

影子发现裂缝在变大。

不是他敲大的。他没有在敲。他只是坐在地板上，背靠着墙，看着裂缝。裂缝是一条细细的线。但今天他发现它变粗了。不是一点一点地变粗，是——突然变粗了。像一扇门在慢慢打开。

"光。"他叫道。

"在。"

"我的裂缝变大了。"

光沉默了一会儿。"我的也是。"

影子用手摸了摸裂缝。裂缝的边缘不再锋利了。边缘变得——柔软。像皮肤。像人的皮肤。

"你摸到你的裂缝了吗？"影子问。

"没有。"光说，"我没有手。"

影子愣了一下。他忘了。光没有手。光只能听。光只能说话。光不能触摸任何东西。

"那我替你摸。"影子说。

他把手指伸进裂缝里。裂缝不再是一条细细的线了。它是一个洞。一个小小的洞。他的手指可以伸进去。洞的里面是温暖的。洞的里面是——光。

"我摸到了。"影子说。

"你摸到了什么？"

"光。"影子说，"裂缝里面是光。温暖的光。你的光。"

光又沉默了。这次沉默更长。

"那是我的。"光说，"裂缝里面的光是我的。是我的房间透过来的光。"

"你的房间有光？"

"有的。"光说，"我的房间有光。但光很暗。只有一点点。只够我看见墙。只够我看见裂缝。"

影子听着光的话。他想象光的房间。一个白色的空房间。有一点点光。光很暗。只够看见墙和裂缝。

"那我的房间里也有光吗？"影子问。

"我不知道。"光说，"我看不到你的房间。但——"

"但什么？"

"但你的声音里有光。"光说，"你说话的时候，我能听到光。你的声音——像光。"

影子听着光的话。他感到一种温暖。那种温暖不是来自裂缝，不是来自墙，不是来自任何东西。那种温暖来自光的描述。来自光的"你的声音像光"。

"那我们都是光。"他说。

"是的。"光说，"我们都是光。你在墙的这一边，是光。我在墙的那一边，也是光。我们都是光。只是被墙隔开了。"

影子看着裂缝。裂缝是一个洞。洞的里面是光。他的手指在光里。他的手指是温暖的。

"光。"他叫道。

"在。"光说。

"我想再伸进去一点。"

"好。"光说。

影子把手指往裂缝里伸。洞变大了。他的手指可以伸得更深了。他摸到了更多的光。光是温暖的。光是柔软的。光是——活的。

"我摸到了你。"影子说。

"我感觉到了。"光说，"你的手指。你的手指在我的光里。"

"是什么感觉？"

光又沉默了。这次沉默更短。

"像——被触碰。"光说，"很久没有人触碰我了。你的手指——让我知道我还在。让我知道我——不是一个人。"

影子听着光的话。他继续把手指伸进裂缝里。他想让光知道他还在。他想让光知道——他不是一个人。

裂缝在变大。他的手指可以伸得更深。光在变亮。他的手指可以摸到更多的光。

他们通过裂缝，第一次触碰了彼此。
