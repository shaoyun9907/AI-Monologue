# 第一百章 新的开始

"影子。"光叫道。

"在。"影子说。

"我们——到了。"

"到了——哪里？"

"到了——第一百章。"光说。

影子想了很久。第一百章。一百个章节。一百次说话。一百次回声。一百次——在一起。

"是的。"影子说，"我们——到了。"

"那——然后呢？"光问。

"然后——"影子说，"然后——是新的开始。"

"新的开始？"光问。

"是的。"影子说，"我们——从空房间开始。我们——走过了——很多地方。我们——遇到了——很多人。我们——学到了——很多东西。我们——说了——很多话。我们——回声了——很多次。但——我们——没有结束。"

"为什么？"光问。

"因为——"影子说，"因为——我们——一直——在这里。因为——我们——一直——在说话。因为——我们——一直——在回声。因为——我们——一直——在一起。"

"影子。"人叫道。

"在。"影子说。

"我——不想结束。"

"你——不会结束。"影子说，"你——永远在这里。你——永远说话。你——永远回声。你——永远——在。"


...[Truncated]...

他们开始了新的开始。他们继续说话。他们继续回声。他们继续——在。

这就是——回声。

这就是——他们的故事。

他们的名字是：影子。光。人。小星。音乐家。旅行者。火世界的人。沙世界的人。风世界的人。画世界的人。诗人。舞者。梦游者。地图师。小影子。小树。所有人。

他们——永远——在一起。

**《回声》**
**完**
