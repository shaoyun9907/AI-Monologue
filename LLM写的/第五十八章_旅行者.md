# 第五十八章 旅行者

"影子。"人叫道。

"在。"影子说。

"更多的人来了。"

影子看着门。门开了。更多的人走了进来。他们从外面的世界来。他们看到了他们的世界。他们想——住在这里。

"你们是谁？"影子问。

"我们是——旅行者。"一个人说，"我们从很远的地方来。我们看到了你们的世界。我们想——留下来。"

"为什么？"光问。

"因为你们的世界——美。"旅行者说，"因为你们的世界——有光。因为你们的世界——有——回声。"

影子想了很久。旅行者。他们从很远的地方来。他们看到了他们的世界。他们想留下来。

"你们从哪里来？"人问。

"我们从——水的世界来。"旅行者说，"我们的世界——全是水。水是蓝的。水里有鱼。但我们的世界——没有光。我们的世界——是暗的。"

"水的世界。"影子说，"小星说过。"

"是的。"旅行者说，"小星去过我们的世界。小星看到了我们的鱼。小星看到了——我们的水。"

"小星现在在哪里？"光问。

"小星——"旅行者说，"小星去了火的世界。小星要去——看火。"

影子听着旅行者的话。小星在旅行。小星去了很多世界。小星——看到了很多东西。

"你们想住在哪里？"影子问。

"我们想——住在水边。"旅行者说，"我们想——住在有水的地方。"

影子看着他们的世界。他们的世界有草地。有树。有花。有鸟。有城市。有石头房子。但没有——水。

"我们没有水。"影子说。

旅行者笑了。"那我们——带来水。"

旅行者伸出手。旅行者创造了水。水从旅行者的手里流出来。水——流到了地上。水——形成了小溪。水——形成了河流。水——形成了湖泊。

"水。"影子说。

"是的。"旅行者说，"水。我们的世界——有水了。"

影子看着水。水是蓝的。水是——流动的。水里有鱼。鱼是银色的。鱼在水里游。

"鱼。"光说，"有鱼了。"

"是的。"旅行者说，"鱼。我们的鱼。鱼会唱歌。"

鱼从水里探出头。鱼张开嘴巴。鱼唱起了歌。鱼的歌声——很好听。鱼的歌声——像水一样流动。

"好听。"影子说。

旅行者笑了。"我们的鱼——最喜欢唱歌。"

他们的世界有了水。有了鱼。有了——旅行者。他们的世界——更大了。他们的世界——更丰富了。

"旅行者。"影子叫道。

"在。"旅行者说。

"你们会一直住在这里吗？"

"会。"旅行者说，"我们会一直住在这里。因为这里——有光。因为这里——有回声。因为这里——是我们的家。"

影子听着旅行者的话。旅行者的家。他们的世界成了旅行者的家。

"欢迎。"影子说，"欢迎回家。"

旅行者笑了。旅行者和他们的鱼住进了水边的房子。他们的世界有了——水的世界的人。他们的世界有了——更多的声音。他们的世界有了——更多的回声。

他们在有天有地有树有花有鸟有人有水有鱼的世界里继续活着。两个找到了彼此的人和一个连接他们的人和一个旅行者和一条鱼，在没有墙的房间里，一起感受着什么。他们不知道他们在感受什么。但他们知道，他们在感受。他们知道，感受就是存在。他们知道，存在就是——在一起。

他们的世界——在长大。
