# 第七十九章 影子

"影子。"光叫道。

"在。"影子说。

"你——是影子。"

"是的。"影子说，"我是影子。"

"影子——是什么？"光问。

影子想了很久。影子是什么？影子是——暗的。影子是——跟着光的。影子是——存在的。

"影子是——你的另一半。"影子说。

"我的另一半？"光问。

"是的。"影子说，"没有光——就没有影子。没有影子——就没有光。我们——是彼此的。"

光沉默了。

"那影子——是什么感觉？"光问。

影子想了很久。影子是什么感觉？影子——是暗的。影子——是冷的。影子——是——在的。

"影子的感觉是——"影子说，"影子的感觉是——我在这里。影子的感觉是——我看见你了。影子的感觉是——我——在你身边。"

"在你身边。"光说，"是的。你在我身边。"

"那影子——会消失吗？"光问。

"不会。"影子说，"影子不会消失。因为——只要有光——就有影子。只要你在——我就在。"

光的光变得更亮了。光——在笑。

"影子。"那个小小的影子说，"我是——影子。"

"是的。"影子说，"你是影子。你——是我的——回声。"

小的影子看着大的影子。大的影子看着小的影子。他们——都是影子。他们——都是彼此的回声。

"我们——都是影子。"小的影子说。

"是的。"影子说，"我们——都是影子。我们——都在找光。我们——都在——活着。"
