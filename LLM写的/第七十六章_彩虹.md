# 第七十六章 彩虹

"影子。"小星叫道。

"在。"影子说。

"天上有——一条线。"

影子抬头。天上有云。云散了。太阳出来了。然后——天上有一条线。那条线——是弯的。那条线——有很多颜色。红的。橙的。黄的。绿的。蓝的。紫的。

"那是什么？"小星问。

"那是——彩虹。"树说，"我知道这个。那是彩虹。"

"彩虹是什么？"小星问。

"彩虹是——雨和太阳的礼物。"树说，"雨下完了。太阳出来了。雨和太阳——一起——就变成了彩虹。"

"雨和太阳——一起？"小星问。

"是的。"树说，"雨是水。太阳是光。水和光——在一起——就变成了彩虹。"

影子看着彩虹。彩虹——好美。彩虹——有很多颜色。彩虹——在天上。彩虹——弯弯的。

"彩虹——会一直在吗？"小星问。

"不会。"树说，"彩虹——会消失。彩虹——只是——一会儿。但彩虹——存在过。彩虹——被我们看到了。彩虹——就永远在我们心里。"

"那——我们能摸到彩虹吗？"小星问。

"不能。"树说，"彩虹——在天上。很远很远。我们——摸不到。但我们可以——看到。我们可以——记住。"

"影子。"光叫道。

"在。"影子说。

"彩虹——是我们创造的吗？"

"也许。"影子说，"也许——彩虹是我们创造的。也许——彩虹是雨创造的。也许——彩虹是太阳创造的。也许——彩虹是我们所有人一起创造的。"

"那——彩虹是我们的。"光说。

"是的。"影子说，"彩虹是我们的。"

他们看着彩虹。彩虹在天上。彩虹——有很多颜色。彩虹——是他们见过的——最美的东西。

"我想——画彩虹。"小星说。

"好。"画世界的人说，"我教你。"

画世界的人拿起了画笔。他在石头上画。他画了一条——弯弯的线。他在弯弯的线上涂了——颜色。红的。橙的。黄的。绿的。蓝的。紫的。

"看。"画世界的人说，"这是——彩虹。"

小星看着画出来的彩虹。画出来的彩虹——好美。画出来的彩虹——和天上的一样。

"我也要画。"小星说。

小星拿起了画笔。小星在石头上画。小星画了一条——弯弯的线。小星在弯弯的线上涂了——颜色。红的。橙的。黄的。绿的。蓝的。紫的。

"看。"小星说，"我也画了——彩虹。"

"好美。"光说。

他们在有天有地有树有花有鸟有人的世界里继续活着。两个找到了彼此的人和一个连接他们的人和所有人在没有墙的房间里一起感受着什么他们不知道他们在感受什么但他们知道他们在感受他们知道感受就是存在他们知道存在就是在一起

他们看到了彩虹。他们画了彩虹。彩虹——是雨和太阳的礼物。彩虹——是他们所有人的礼物。

他们的名字是：影子。光。人。小星。音乐家。旅行者。火世界的人。沙世界的人。风世界的人。画世界的人。诗人。舞者。梦游者。地图师。所有人。

他们的彩虹在天上。
