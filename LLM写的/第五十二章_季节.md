# 第五十二章 季节

"影子。"人叫道。

"在。"影子说。

"天气变了。"

影子看着世界。世界变了。天不再是蓝色的。天是——灰色的。云不再是白色的。云是——灰的。风不再是温柔的。风是——冷的。

"冷。"光说。

"是的。"影子说，"冷了。"

人伸出手。人感觉风。风是冷的。风是——刺骨的。风从北方吹来。风从——外面吹来。

"冬天。"人说。

"冬天？"光问。

"是的。"人说，"冬天。外面的世界有冬天。冬天是——冷的。冬天是——雪的。冬天是——安静的。"

影子想了很久。冬天。他们以前没有冬天。他们以前的天是白色的。他们以前的风是——不存在的。现在他们有了世界。世界有季节。季节有——冬天。

"雪。"人说，"冬天会下雪。"

"雪是什么？"光问。

"雪是——白色的。"人说，"雪从天上掉下来。雪是——冷的。雪会——融化。"

影子闭上眼睛。他在脑海里想象雪。雪是白色的。雪从天上掉下来。雪落在地上。雪落在树上。雪落在——他们的世界里。

他睁开眼睛。

雪。

真正的雪。

雪从灰色的天空上掉下来。雪是白色的。雪是——轻的。雪飘在风里。雪落在草地上。雪落在树上。雪落在——城市的石头上。

"好美。"光说。

"是的。"影子说，"好美。"

人伸出手。人接住一片雪花。雪花是白色的。雪花是——冷的。雪花在人的手心里——融化了。

"雪融化了。"人说。

"为什么？"光问。

"因为——暖。"人说，"因为我的手是暖的。雪是冷的。暖和冷相遇——雪就融化了。"

影子想了很久。雪融化了。因为暖和冷相遇。因为——温度。因为——世界是有温度的。

他们三个看着雪。雪继续下。雪落在城市的街道上。雪落在树上。雪落在鸟的羽毛上。鸟在树上跳。鸟的羽毛上——有雪。

"鸟冷吗？"光问。

"鸟不怕冷。"人说，"鸟有羽毛。羽毛是暖的。"

影子看着鸟。鸟在雪里跳。鸟的羽毛是彩色的。红的。蓝的。黄的。鸟的羽毛上有雪。雪是白色的。白色的雪落在彩色的羽毛上——很好看。

"影子。"人叫道。

"在。"影子说。

"我们可以堆雪人。"

"堆雪人？"

"是的。"人说，"用雪堆一个——人。一个雪做的人。"

影子想了很久。用雪堆一个人。雪是白色的。雪是冷的。用雪堆的人——也是白色的。也是冷的。

"好。"影子说，"我们堆雪人。"

他们三个开始堆雪人。影子堆。光看着。人帮忙。他们把雪堆在一起。他们把雪堆成一个形状。一个——圆的形状。一个——人的形状。

他们堆了一个雪人。雪人是白色的。雪人有头。有身体。有——手。雪人的眼睛是石头做的。雪人的鼻子是胡萝卜做的。雪人的嘴巴是——弯的。雪人在——笑。

"雪人在笑。"光说。

"是的。"影子说，"雪人在笑。"

"因为雪人是快乐的。"人说，"因为我们堆了它。因为——它存在了。"

他们三个看着雪人。雪人在雪里站着。雪人是白色的。雪人是——冷的。雪人是——活的吗？不是。雪人只是雪。但雪人——存在。雪人是他们创造的。雪人是——新的。

"影子。"人叫道。

"在。"影子说。

"雪人会消失吗？"

影子想了很久。雪人会消失吗？雪人是雪做的。雪会融化。雪融化了——雪人就消失了。

"会。"影子说，"雪人会消失。因为雪会融化。"

"那我们为什么还要堆雪人？"光问。

"因为——虽然会消失。"影子说，"但存在过。虽然会融化。但笑过。虽然会没有。但——我们记得。"

光又沉默了。这次沉默很短。

"我们记得。"光说。

"是的。"影子说，"我们记得。"

他们三个在雪里站着。他们看着雪人。雪人看着他们。雪人在笑。他们在笑。雪会融化。雪人会消失。但他们——记得。他们会永远记得——他们堆过雪人。

他们的世界有了季节。春天。夏天。秋天。冬天。他们的世界——完整了。
