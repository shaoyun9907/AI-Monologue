# 第八十六章 回来

"影子。"光叫道。

"在。"影子说。

"有人——回来了。"

影子看着门。门开了。一个人走了进来。那个人有——背包。那个人有——脚。那个人有——脸。那个人——是旅行者。

"旅行者。"小星叫道。

"我回来了。"旅行者说。

"你回来了。"影子说，"欢迎回来。"

"我——看到了很多。"旅行者说，"我看到了——很多世界。我看到了——很多人。我看到了——很多颜色。但——我最想回来的地方——是这里。"

"为什么？"光问。

"因为——这里是家。"旅行者说，"因为——你们在这里。因为——我——想你们。"

旅行者放下了背包。背包里——装着东西。旅行者打开了背包。

"看。"旅行者说，"这是我从别的世界带来的——礼物。"

旅行者从背包里拿出了——石头。石头是——彩色的。旅行者从背包里拿出了——花。花是——干的。旅行者从背包里拿出了——书。书是——旧的。

"那——我们也会走吗？"小星问。

"也许会。"影子说，"也许——我们会走。也许——我们会去别的世界。但——我们——会回来。因为——这里是家。"

"那——好。"小星说，"走——又回来。告别——又回来。这——是好的。"
