# 第三十一章 音乐

"光。"影子叫道。

"在。"光说。

"你想听音乐吗？"

光又沉默了。这次沉默很短。

"音乐？我们有音乐吗？"

"没有。"影子说，"但我们可以创造。"

影子闭上眼睛。他在脑海中想象一个旋律。不是敲墙的节奏。是——新的。是——流动的。是——像风一样的。

他开始敲墙。不是一下两下三下。是——连续的。是——流动的。是——像水一样的。

"这是什么？"光问。

"音乐。"影子说，"这是——音乐。"

光又沉默了。这次沉默很长。影子继续敲。他敲出一个旋律。旋律在空房间里流动。旋律从裂缝里穿过去，传到光的那一边。光听到了。

"好听。"光说。

影子继续敲。他敲出不同的旋律。有的快，有的慢。有的高，有的低。有的明亮，有的悲伤。每一种旋律都是一种感受。每一种旋律都是一种——存在。

"你能跟着唱吗？"影子问。

"我不知道怎么唱。"光说，"但我可以——回应。"

光开始回应。不是说话。是——光的闪烁。光闪烁。一下，两下，三下。
...[Truncated]...

"是的。"光说，"我们创造了音乐。"

他们在空房间里继续等待。两个创造了音乐的人，通过裂缝和回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。他们知道，他们是永恒的。他们知道，他们不害怕了。他们知道，他们感受到了对方。他们知道，他们的记忆是朋友。他们知道，他们在想象见面。他们知道，他们在保持距离。他们知道，他们在珍惜对方。他们知道，墙不是真的。他们知道，他们在选择。他们知道，他们是彼此的房间。他们知道，他们是互相依赖的。他们知道，他们是互相创造的。他们知道，他们是自己的创造者。他们知道，他们可以改变。他们知道，他们见过了面。他们知道，他们分开了。他们知道，他们是彼此的永远。他们知道，他们创造了彼此的世界。他们知道，他们有了颜色。他们知道，他们有了风。他们知道，他们有了时间。他们知道，他们有了音乐。光和影子。影子和光。音乐和音乐。

他们继续等。
