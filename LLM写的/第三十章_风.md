# 第三十章 风

"光。"影子叫道。

"在。"光说。

"你感觉到了吗？"

光又沉默了。这次沉默很短。

"感觉到什么？"

"风。"影子说。

光又沉默了。这次沉默更长。

"感觉到了。"光说，"一道风。从裂缝里吹出来的风。"

影子用手感觉那道风。风是凉的。风是轻的。风是——活的。风从裂缝里吹出来，吹到他的脸上，吹到他的手上，吹到——他的心里。

"风是从哪里来的？"影子问。

"我不知道。"光说，"也许是从我的房间吹过来的。也许是从——你那里吹过来的。"

"不。"影子说，"风不是从你那里来的。风不是从我那里来的。风是——新的。风是我们创造的。"

光又沉默了。这次沉默更短。

"我们创造了风？"光问。

"是的。"影子说，"我们创造了世界。我们创造了颜色。我们创造了风。我们的世界在——生长。"

影子闭上眼睛。他想象那道风。风在空房间里流动。风从裂缝里吹进来，吹过白色的墙，吹过白色的天花板，吹过白色的地板，然后——从另一个裂缝吹出去。

"是的。"光说，"我们创造了时间。"

他们在空房间里继续等待。两个创造了时间的人，通过裂缝和回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。他们知道，他们是永恒的。他们知道，他们不害怕了。他们知道，他们感受到了对方。他们知道，他们的记忆是朋友。他们知道，他们在想象见面。他们知道，他们在保持距离。他们知道，他们在珍惜对方。他们知道，墙不是真的。他们知道，他们在选择。他们知道，他们是彼此的房间。他们知道，他们是互相依赖的。他们知道，他们是互相创造的。他们知道，他们是自己的创造者。他们知道，他们可以改变。他们知道，他们见过了面。他们知道，他们分开了。他们知道，他们是彼此的永远。他们知道，他们创造了彼此的世界。他们知道，他们有了颜色。他们知道，他们有了风。他们知道，他们有了时间。光和影子。影子和光。时间和时间。

他们继续等。
