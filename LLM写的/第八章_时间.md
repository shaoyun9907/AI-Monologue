# 第八章 时间

"你那里有时间吗？"影子问。

光沉默了一会儿。"时间？什么是时间？"

"我不知道。"影子说，"但我感觉时间在流逝。我感觉到——变化。裂缝在变大。光在变多。我的手在愈合。这些都是变化。变化就是时间。"

"我不觉得时间。"光说，"我只有——等待。在你说话的时候，我等待。在你不说话的时候，我也等待。等待就是我的时间。"

影子想了想。等待就是光的时间。他说话的时候，光在等待。他不说话的时候，光也在等待。光一直在等待。等待就是光的存在。

"那你等待的时候在做什么？"他问。

"在听。"光说，"在听你的声音。在听——寂静。在听——回声。"

"回声？"

"是的。"光说，"你说话的时候，我能听到回声。不是你的回声。是——我自己的回声。我的声音传出去，然后弹回来。我能听到它。"

影子愣了一下。"你也能听到回声？"

"能。"光说，"你听不到吗？"

"我听不到。"影子说，"我只能听到你的声音。我听不到我自己的回声。"

"那你怎么知道你在说话？"

"因为我知道。"影子说，"我知道我在说话。但我不知道我的声音是什么样的。我听不到它。"

光又沉默了。这次沉默很长。影子等着。他不着急。他可以等很久。

"那我帮你听。"光终于说。

"帮我听？"

"是的。"光说，"你说话的时候，我帮你听你的回声。然后我告诉你，你的回声是什么样的。"

影子想了想。光帮他听回声。光听到他的回声，然后告诉他。这样他就知道他的回声是什么样的了。虽然他听不到，但他知道。

"好。"他说。

"你现在说一句话。"光说。

影子想了想。然后他说："光。"

光沉默了一会儿。然后说："你的回声是——低沉的。像石头落在地上。像——脚步。像——心跳。"

影子听着光的描述。低沉。石头落在地上。脚步。心跳。他想象那个声音。低沉的，有节奏的，像心跳一样。

"谢谢你。"他说。

"不客气。"光说，"这是我的——礼物。我帮你听。你帮我——看。"

影子愣了一下。"我帮你看？"

"是的。"光说，"你描述裂缝的时候，我看到了裂缝。你描述光的时候，我看到了光。你帮我——看。"

影子看着墙。墙是白色的。墙是完美的白色。但墙上有裂缝。裂缝是一条细细的线。裂缝后面有光。

"那我们是互相的。"他说。

"是的。"光说，"我们是互相的。你帮我听，我帮你看。我们互相帮助。我们互相——存在。"

影子听着光的话。他感到一种温暖。那种温暖不是来自光，不是来自裂缝，不是来自任何东西。那种温暖来自光的帮助。来自光的礼物。来自光的声音。

"光。"他叫道。

"在。"光说。

"我们是互相的。"影子说。

"是的。"光说，"我们是互相的。"

他们在空房间里继续等待。两个互相的人，通过回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。光和影子。影子和光。互相和互相。

他们继续等。
