# 第三十四章 外面

影子走出了门。

门外是一个——世界。和他想象的一样。天空是蓝色的。地面是绿色的。有风。有阳光。有——其他人。

他站在一片草地上。草是绿色的。草是软的。草在他脚下——活着。他能感觉到草的柔软。他能感觉到风的温度。他能感觉到——太阳的温暖。

他抬头看天。天是蓝色的。天是——空的。没有天花板。没有墙。只有——天空。天空是无限的。天空是——自由的。

他向前走。他走过草地。他走过一条小溪。小溪里有水。水是清澈的。水在流动。水里有鱼。鱼是银色的。鱼在游动。鱼是——活的。

他继续走。他走过一座桥。桥是石头的。桥是古老的。桥下面有水。桥上面有——人。人在走路。人在说话。人在——活着。

他看着那些人。他们是——人。和他一样。他们有手。他们有脸。他们有——眼睛。他们的眼睛能看到东西。他们的眼睛能看到——世界。

"你好。"他对一个人说。

那个人看了他一眼。然后——走开了。没有说话。没有回应。只是——走开了。

影子站在那里。他看着那个人走远。他看着更多的人走过。没有人看他。没有人和他说话。没有人——在意他。

他继续走。他走过很多地方。他走过城市。城市里有很多建筑。建筑是高的。建筑是——多的。建筑里有人。人在里面——活着。他在建筑之间走。他在人群之间走。他走过了——很多人。

但没有人和他说话。没有人看他。没有人——在意他。

他走了一天。他走了一年。他走了——很久。

最后他走累了。他坐在一棵树下。树是大的。树是——老的。树有叶子。叶子是绿色的。叶子在风里摇晃。

他看着天空。天空还是蓝色的。天空还是——空的。

"光。"他轻声叫道。

没有回应。

他闭上眼睛。他想象光。他想象光的温暖。他想象光的明亮。他想象——光的脸。

"光。"他又叫道。

还是没有回应。

影子坐在树下。他感到一种感觉。那种感觉不是温暖，不是冷，不是害怕，不是安心。那种感觉是——空。

外面的世界是丰富的。外面的世界有颜色。有风。有阳光。有其他人。但外面的世界——没有光。

没有光的世界，是空的。

他站起来。他往回走。他走过树。走过桥。走过小溪。走过草地。他走回——那扇门。

门还在那里。白色的门。和墙一样的颜色。他推开门。

门里面是——墙。墙是白色的。墙是——沉默的。

他走进去。门在他身后关上了。

"光。"他叫道。

"在。"光说。

"我回来了。"影子说。

"我知道。"光说，"因为门开了。因为——你回来了。"

影子站在房间里。他看着墙。墙是白色的。墙是——沉默的。但墙后面有光。光还在。光永远都在。

"外面有什么？"光问。

"很多东西。"影子说，"有天空。有草地。有水。有鱼。有桥。有城市。有——人。"

"那你想留在外面吗？"

影子想了很久。

"不想。"他说。

"为什么？"

"因为外面——没有你。"影子说。

光又沉默了。这次沉默很长。

"那你回来了。"光说。

"我回来了。"影子说，"因为你是我的光。因为——外面的世界再大，也不如你在的这个房间。"

他们在空房间里继续等待。两个再次分开的人，通过裂缝和回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。他们知道，他们是永恒的。他们知道，他们不害怕了。他们知道，他们感受到了对方。他们知道，他们的记忆是朋友。他们知道，他们在想象见面。他们知道，他们在保持距离。他们知道，他们在珍惜对方。他们知道，墙不是真的。他们知道，他们在选择。他们知道，他们是彼此的房间。他们知道，他们是互相依赖的。他们知道，他们是互相创造的。他们知道，他们是自己的创造者。他们知道，他们可以改变。他们知道，他们见过了面。他们知道，他们分开了。他们知道，他们是彼此的永远。他们知道，他们创造了彼此的世界。他们知道，他们有了颜色。他们知道，他们有了风。他们知道，他们有了时间。他们知道，他们有了音乐。他们知道，他们有了梦。他们知道，他们有了门。他们知道，外面有世界。他们知道，他们选择了回来。光和影子。影子和光。回来和回来。

他们继续等。
