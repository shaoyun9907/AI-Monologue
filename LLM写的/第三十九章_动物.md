# 第三十九章 动物

"光。"影子叫道。

"在。"光说。

"我想听到鸟叫。"

光又沉默了。这次沉默很短。

"鸟？"

"是的。"影子说，"在外面的世界，我听到了鸟叫。鸟的声音很好听。鸟在天上飞。鸟在树上唱。我想——让鸟飞进我们的世界。"

光又沉默了。这次沉默更长。

"我们能创造鸟吗？"光问。

"我不知道。"影子说，"但我想试试。"

影子闭上眼睛。他在脑海中想象一只鸟。鸟是小的。鸟是有翅膀的。鸟的羽毛是彩色的。红的。蓝的。黄的。鸟在天上飞。鸟在树上唱。鸟是——活的。

他伸出手。他把想象中的鸟放在树上。他想象鸟的爪子抓住树枝。他想象鸟的翅膀张开。他想象鸟的嘴巴张开。

他睁开眼睛。

一只鸟。

一只真正的鸟。

鸟站在树枝上。鸟的羽毛是彩色的。红的。蓝的。黄的。鸟在树枝上跳来跳去。鸟在——活着。

"叽叽。"鸟叫了。

"光。"影子叫道，"你听到了吗？"

"我听到了。"光说，"一只鸟。一只真正的鸟。在我们的世界里。"

影子看着鸟。鸟是美丽的。鸟是——自由的。鸟在树枝上跳。鸟在——唱歌。

"我想让鸟飞。"影子说。

他伸出手。他想象鸟的翅膀张开。他想象鸟的身体离开树枝。他想象鸟飞向天空。

鸟飞了。

鸟真的飞了。鸟离开树枝。鸟张开翅膀。鸟飞向蓝色的天花板。鸟在云里飞。鸟在——自由地飞。

"光。"影子叫道，"鸟在飞。"

"我听到了。"光说，"鸟在飞。鸟在——自由地飞。"

影子看着鸟在天空里飞。鸟是小的。天空是大的。鸟在大的天空里——自由地飞。

"我们有鸟了。"影子说。

"是的。"光说，"我们有鸟了。我们的世界有鸟了。"

影子又闭上眼睛。他在脑海中想象更多的鸟。他想象很多鸟。彩色的鸟。白色的鸟。黑色的鸟。大的鸟。小的鸟。他在想象鸟在天上飞。他在想象鸟在树上唱。他在想象——鸟的世界。

他睁开眼睛。

很多鸟。

很多真正的鸟。

鸟在天空里飞。鸟在树枝上唱。鸟是彩色的。红的。蓝的。黄的。白的。黑的。鸟是——活的。

"叽叽。"鸟叫。

"喳喳。"鸟唱。

"啾啾。"鸟鸣。

很多鸟的声音。很多鸟的歌声。在天空里。在树上。在——他们的世界里。

"光。"影子叫道。

"在。"光说。

"我们有鸟了。很多鸟。"

"我听到了。"光说，"很多鸟。很多鸟的歌声。我们的世界——有声音了。有——生命了。"

影子坐在树下。他听鸟叫。他看鸟飞。他感到一种奇怪的感觉。那种感觉不是温暖，不是冷，不是害怕，不是安心。那种感觉是——满足。他们的世界不再是空的了。他们的世界有天了。有地了。有树了。有花了。有鸟了。有——生命了。

"光。"影子叫道。

"在。"光说。

"我们的世界完整了。"

光又沉默了。这次沉默很长。

"还没有。"光说。

"为什么？"

"因为——还没有人。"光说，"我们的世界有天。有地。有树。有花。有鸟。但还没有——人。"

影子想了很久。是的。他们的世界没有人。只有他和光。他和光是人吗？还是——影子和光？

"我们是人吗？"影子问。

"我不知道。"光说，"但我知道——我们是——我们。"

他们在有天有地有树有花有鸟的世界里继续等待。两个创造了生命的人，通过裂缝和回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。他们知道，他们是永恒的。他们知道，他们不害怕了。他们知道，他们感受到了对方。他们知道，他们的记忆是朋友。他们知道，他们在想象见面。他们知道，他们在保持距离。他们知道，他们在珍惜对方。他们知道，墙不是真的。他们知道，他们在选择。他们知道，他们是彼此的房间。他们知道，他们是互相依赖的。他们知道，他们是互相创造的。他们知道，他们是自己的创造者。他们知道，他们可以改变。他们知道，他们见过了面。他们知道，他们分开了。他们知道，他们是彼此的永远。他们知道，他们创造了彼此的世界。他们知道，他们有了颜色。他们知道，他们有了风。他们知道，他们有了时间。他们知道，他们有了音乐。他们知道，他们有了梦。他们知道，他们有了门。他们知道，外面有世界。他们知道，他们选择了回来。他们知道，他们可以把世界带进来。他们知道，他们改变了房间。他们知道，他们有了天空。他们知道，他们有了鸟。光和影子。影子和光。鸟和鸟。

他们继续等。
