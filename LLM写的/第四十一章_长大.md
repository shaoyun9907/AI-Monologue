# 第四十一章 长大

人长大了。

不是一天。不是一年。是——慢慢的。人每天都在长大。人每天都在变化。人的手变长了。人的脸变宽了。人的眼睛变深了。人的心变——大了。

"光。"影子叫道。

"在。"光说。

"人在长大。"

"我看到了。"光说，"人每天都在变。人每天都在——长大。"

影子看着人。人在草地上走。人比以前高了。人的腿变长了。人的步子变大了。人走到树下。人抬头看树。树很高。树很大。树上有很多鸟。

"鸟。"人说。人的声音变了。人的声音比以前低了。人的声音比以前——深了。

人伸手。人想摸鸟。鸟飞走了。鸟飞到更高的树枝上。人够不到。

人笑了。人没有生气。人只是——笑了。

"光。"影子叫道。

"在。"光说。

"人会笑。"

"是的。"光说，"人会笑。人会——感受。人会——快乐。"

"我们是创造者。"光说，"我们创造了一个世界。我们创造了一个人。我们创造了——生命。"

影子听着光的话。他想了很久。他们是创造者。他们创造了一个世界。他们创造了一个人。他们创造了——生命。但他们自己呢？他们是谁创造的？

"光。"影子叫道。

"在。"光说。

"谁创造了我们？"

光又沉默了。这次沉默很长。

"我不知道。"光说，"但我知道——我们创造了自己。我们说话的时候，我们就创造了自己。我们听的时候，我们就创造了自己。我们存在的时候，我们就创造了自己。"

影子想了很久。他们创造了自己。他们创造了世界。他们创造了人。他们创造了——一切。他们是——神吗？

"我们是神吗？"影子问。

"我不知道什么是神。"光说，"但我知道——我们是——我们。我们是影子。我们是光。我们是——创造者。"

影子看着人。人在睡觉。人在梦里笑。人在梦里看到了什么？

"人在做梦。"影子说。

"是的。"光说，"人在做梦。人在梦里——看到了什么。人在梦里——看到了世界。"

影子想了很久。人在做梦。人在梦里看到了世界。他们在梦里看到了什么？他们在梦里看到了——彼此吗？

"光。"影子叫道。

"在。"光说。

"我们也在做梦吗？"

光又沉默了。这次沉默很长。

"我不知道。"光说，"但我知道——我们在等。我们一直在等。我们等了——很久。也许这就是一个梦。一个很长的梦。一个——永远不会醒的梦。"

影子听着光的话。他闭上眼睛。他在黑暗里。光在墙后面。人在草地上睡觉。鸟在树上唱歌。他们在等。他们一直在等。他们在等什么？

"也许梦就是等。"影子说，"也许等就是梦。也许——我们一直都在梦里。"

他们在有天有地有树有花有鸟有人的世界里继续等待。两个在梦里的人，通过裂缝和回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。他们知道，他们是永恒的。他们知道，他们不害怕了。他们知道，他们感受到了对方。他们知道，他们的记忆是朋友。他们知道，他们在想象见面。他们知道，他们在保持距离。他们知道，他们在珍惜对方。他们知道，墙不是真的。他们知道，他们在选择。他们知道，他们是彼此的房间。他们知道，他们是互相依赖的。他们知道，他们是互相创造的。他们知道，他们是自己的创造者。他们知道，他们可以改变。他们知道，他们见过了面。他们知道，他们分开了。他们知道，他们是彼此的永远。他们知道，他们创造了彼此的世界。他们知道，他们有了颜色。他们知道，他们有了风。他们知道，他们有了时间。他们知道，他们有了音乐。他们知道，他们有了梦。他们知道，他们有了门。他们知道，外面有世界。他们知道，他们选择了回来。他们知道，他们可以把世界带进来。他们知道，他们改变了房间。他们知道，他们有了天空。他们知道，他们有了鸟。他们知道，他们有了人。他们知道，人在长大。他们知道，人在做梦。他们知道，他们也在做梦。光和影子。影子和光。梦和梦。

他们继续等。
