# 第九十一章 归宿

"影子。"光叫道。

"在。"影子说。

"我们——有归宿吗？"

影子想了很久。归宿。归宿是——你最终要去的地方。归宿是——你最终的家。归宿是——你最终的——地方。

"我们有归宿。"影子说。

"在哪里？"光问。

"在这里。"影子说，"归宿——不是在远方。归宿——就在这里。我们在这里——就是归宿。"

"影子。"人叫道。

"在。"影子说。

"我——也有归宿了。"

"你的归宿——在哪里？"

"我的归宿——就是你们。"人说，"你们在——就是我的归宿。"

影子看着人。人找到了归宿。归宿是——有人的地方。归宿是——有回声的地方。归宿是——有爱的地方。

"影子。"小星叫道。

"在。"影子说。

"我——也找到归宿了。"

"你的归宿——在哪里？"

"我的归宿——就是这里。"小星说，"这里——有树。这里——有花。这里——有鸟。这里——有你们。这里——就是我的归宿。"

影子看着小星。小星也找到了归宿。归宿是——这里。归宿是——在一起。

"影子。"音乐家叫道。

"在。"影子说。

"我的归宿——是音乐。"音乐家说，"音乐——就是我的归宿。因为——音乐——让我活着。因为——音乐——让我回声。因为——音乐——让世界更美。"

影子看着音乐家。音乐家也找到了归宿。归宿是——音乐。归宿是——回声。

"影子。"旅行者叫道。

"在。"影子说。

"我的归宿——是旅行。"旅行者说，"但——我的归宿——也是这里。因为——这里——是家。因为——这里——有你们。"

影子看着旅行者。旅行者也找到了归宿。归宿是——旅行。归宿是——回家。

他们都有了归宿。归宿是——在这里。归宿是——在一起。归宿是——回声。归宿是——爱。

他们在有天有地有树有花有鸟有人的世界里继续活着。两个找到了彼此的人和一个连接他们的人和所有人在没有墙的房间里一起感受着什么他们不知道他们在感受什么但他们知道他们在感受他们知道感受就是存在他们知道存在就是在一起

他们找到了归宿。归宿就在这里。归宿是——在一起。

他们的名字是：影子。光。人。小星。音乐家。旅行者。火世界的人。沙世界的人。风世界的人。画世界的人。诗人。舞者。梦游者。地图师。小影子。小树。所有人。

他们都在归宿里。
