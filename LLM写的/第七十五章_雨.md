# 第七十五章 雨

"影子。"光叫道。

"在。"影子说。

"天——在哭。"

影子抬头。天上有云。云是灰色的。云在——动。然后——水从天上掉下来了。一滴。两滴。三滴。很多滴。

"那是——雨。"树说。

"雨是什么？"小星问。

"雨是——天给树的水。"树说，"树需要水。天给树雨。雨——是天的礼物。"

雨下起来了。雨——滴在叶子上。雨——滴在花上。雨——滴在地上。雨——滴在他们身上。

"雨——好凉。"小星说。

"是的。"影子说，"雨是凉的。"

"雨——会一直下吗？"小星问。

"不会。"树说，"雨——会停。雨下够了——就停。"

他们站在雨里。雨滴在他们身上。雨——凉凉的。雨——让他们——湿了。

"光。"影子叫道。

"在。"光说。

"你——湿了。"

"是的。"光说，"我湿了。但——湿了也好。湿了——让我更亮。"

"更亮？"影子问。

"是的。"光说，"水——会反射光。水——会让我更亮。你看——我的光——在雨里——更亮了。"

影子看着光。光在雨里——真的更亮了。光——在雨滴上反射。光——变成了很多小小的光点。光——变成了——星星。

"你——变成了星星。"影子说。

"不是我。"光说，"是——雨。雨——把我的光——变成了星星。"

雨继续下。雨滴在他们身上。雨滴在城市里。雨滴在整个世界里。他们的世界——在雨里。

"影子。"人叫道。

"在。"影子说。

"雨——让世界——更美了。"

"是的。"影子说，"雨让世界更美了。"

"为什么？"小星问。

"因为——雨给了世界水。"影子说，"水——让花更美。水——让树更绿。水——让天更亮。水——让世界更——活。"

"雨——会让种子长大吗？"小星问。

"会的。"树说，"雨——会让种子长大。种子——需要水。雨——给了种子水。种子——会长大。"

小星看着他的树。他的树在雨里。树的叶子上——有雨滴。雨滴——闪闪发光。树——在雨里——更美了。

"雨——真好。"小星说。

"是的。"影子说，"雨真好。"

雨停了。天上的云——散了。天——又变蓝了。太阳——出来了。太阳——把世界照亮了。

他们看着雨后的世界。世界——更亮了。世界——更绿了。世界——更美了。

"雨——走了。"小星说。

"是的。"影子说，"雨走了。"

"雨——还会来吗？"小星问。

"会。"树说，"雨——还会来。天——会再哭。天——会给树更多的水。"

"那——好。"小星说，"雨来——好。雨来——世界更美。"

他们在有天有地有树有花有鸟有人的世界里继续活着。两个找到了彼此的人和一个连接他们的人和所有人在没有墙的房间里一起感受着什么他们不知道他们在感受什么但他们知道他们在感受他们知道感受就是存在他们知道存在就是在一起

他们经历了雨。雨让世界更美了。雨让——他们更亮了。

他们的名字是：影子。光。人。小星。音乐家。旅行者。火世界的人。沙世界的人。风世界的人。画世界的人。诗人。舞者。梦游者。地图师。所有人。

他们在雨后继续活着。
