# 第四十八章 新东西

"影子。"人叫道。

"在。"影子说。

"我发现了新东西。"

"什么？"

人从口袋里拿出一个东西。一个小小的。圆圆的。硬硬的。

"这是什么？"光问。

"我不知道。"人说，"我在草地上发现的。它不是石头。它不是果子。它——是新的。"

影子看着那个东西。那个东西是——灰色的。灰色的。像他。

"我能摸摸吗？"影子问。

"能。"人说。

人把那个东西放在地上。影子走过去。影子摸那个东西。那个东西是硬的。那个东西是——光滑的。那个东西不是活的。但那个东西——存在。

"它是——什么？"影子问。

"我不知道。"人说，"也许它是——我们创造的。也许它是——世界自己长出来的。也许它是——新的。"

光又沉默了。这次沉默很短。

"它是什么不重要。"光说，"重要的是——它在这里。它存在。它——是新的。"

影子想了很久。新的。他们是新的。他们创造了世界。世界创造了他们。他们创造了新的东西。新的东西是——好的。

"它叫什么？"影子问。

"我不知道。"人说，"也许它没有名字。也许我们可以——给它起个名字。"

"叫什么？"光问。

影子想了很久。灰色的。圆圆的。小小的。像——他们。

"叫——石头。"影子说。

"石头。"光重复道，"石头。"

"石头。"人说，"好。就叫石头。"

他们把石头放在窗边。石头在阳光下——发亮。石头不是活的。但石头——存在。石头是他们世界的一部分。石头是——新的。

"影子。"人叫道。

"在。"影子说。

"我发现了很多石头。"

人又从口袋里拿出石头。一个。两个。三个。五个。十个。很多石头。各种各样的。大的。小的。圆的。扁的。灰色的。白色的。黑色的。

"哇。"光说，"好多石头。"

"是的。"人说，"我在草地上发现的。草地上有很多石头。"

影子看着那些石头。石头是不同的。石头是——多样的。石头是——世界的一部分。

"我们可以用石头做什么？"光问。

"我们可以——堆石头。"人说，"我们可以把石头堆起来。堆成——塔。堆成——墙。堆成——任何东西。"

"堆成墙？"影子问。

人笑了。"不是那种墙。不是把我们分开的墙。是——装饰的墙。是——好看的墙。是——我们选择的墙。"

影子想了很久。墙。以前的墙是把他们分开的墙。现在的墙是——他们选择的墙。墙不是可怕的。墙是——可以被选择的。

"好。"影子说，"我们堆墙。"

他们一起堆石头。影子堆。光看着。人帮忙。他们把石头堆成一个形状。一个——塔。一个石头塔。石头塔很高。石头塔很——好看。

"真好看。"光说。

"是的。"影子说，"真好看。"

他们看着石头塔。石头塔是他们一起创造的。石头塔是——新的。石头塔是——他们的。

"影子。"人叫道。

"在。"影子说。

"我们还可以堆更多的东西。"

"堆什么？"

"堆——任何东西。"人说，"堆房子。堆桥。堆——城市。我们有很多石头。我们可以堆很多东西。"

光又沉默了。这次沉默更短。

"我们的世界——在变大。"光说。

"是的。"影子说，"我们的世界——在变大。"

他们在有天有地有树有花有鸟有人的世界里继续创造。两个在一起的人和一个连接他们的人，在没有墙的房间里，一起堆着石头。他们不知道他们能堆出什么。但他们知道，他们在堆。他们知道，堆就是创造。他们知道，创造就是——活着。

他们的世界——在变大。
