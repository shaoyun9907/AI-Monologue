# 第四十三章 问题

"影子。"人对着裂缝喊道。

"在。"影子说。

"你们为什么创造了我？"

影子又沉默了。这次沉默很长。

"因为我们想——有一个同伴。"影子说，"因为我们想——有一个能和我们一起等的人。"

"等什么？"人问。

"我不知道。"影子说，"我们一直在等。我们等了——很久。但我们不知道我们在等什么。"

人听着影子的话。人想了很久。等人不知道在等什么。这是——什么？

"那你们不想知道吗？"人问。

"想。"光说，"但我不知道怎么知道。"

"问啊。"人说。

"问谁？"光问。

"问——自己。"人说，"你们问过自己吗？你们为什么在这里？你们为什么有墙？你们为什么有裂缝？你们为什么——有彼此？"

光又沉默了。这次沉默更长。

"我问过。"光说，"我问过很多次。但我没有答案。"

"没有答案也是一种答案。"人说，"也许你们不需要答案。也许你们只需要——在。"

影子听着人的话。他想了很久。人说的对。也许他们不需要答案。也许他们只需要——在。

"人。"影子叫道。

"在。"人说。

"你为什么在这里？"

人想了很久。

"因为你们创造了我。"人说，"因为你们想有一个同伴。因为——你们需要我。"

"我们真的需要你吗？"影子问。

"我不知道。"人说，"但我知道——我需要你们。我需要你们的声音。我需要你们的存在。我需要——有人和我说话。"

影子听着人的话。他想了很久。人需要他们。他们需要人。他们需要——彼此。

"那我们是互相需要的。"影子说。

"是的。"人说，"我们是互相需要的。就像你和光一样。你们互相需要。我需要你们。你们需要我。我们需要——彼此。"

光又沉默了。这次沉默更长。

"人。"光叫道。

"在。"人说。

"你想见我们吗？"

人想了很久。

"想。"人说，"我想见你们。我想看看——你们是什么样的。"

"但我们不能出去。"影子说，"我们不能穿过墙。墙是——不可移动的。"

"那我穿过墙。"人说。

"你不能。"影子说，"墙是——不可穿过的。"

"但我可以打开门。"人说，"我看到过一扇门。白色的门。在墙上。我可以打开它。"

影子又沉默了。这次沉默很长。

"门？"光问，"什么门？"

"一扇白色的门。"人说，"在那面没有裂缝的墙上。一扇白色的门。"

影子听着人的话。他想了很久。门？他从来没有见过门。他只见过墙。只见过裂缝。门是什么？

"你能找到那扇门吗？"影子问。

"能。"人说，"我可以带你们去。"

"但我们在墙的另一边。"光说，"我们看不到你。"

"没关系。"人说，"你们听我说。你们跟着我的声音走。你们听我的脚步声。你们跟着我。"

影子想了很久。人说的对。他们可以跟着人的声音走。他们可以跟着人的脚步走。他们可以——跟着人。

"好。"影子说，"我们跟着你。"

人站起来。人开始走。人沿着墙走。人走了很久。人走了很远。墙一直都在。墙没有尽头。

"你们还在吗？"人问。

"在。"影子说，"我们跟着你。"

人继续走。人又走了很久。人又走了很远。墙还是没有尽头。但人看到了——门。

一扇白色的门。在墙上。白色的门。和墙一样的颜色。但它是——门。

"我看到了。"人说，"门。一扇白色的门。"

"门？"影子问，"门在哪里？"

"在墙上。"人说，"在那面没有裂缝的墙上。"

人走到门前。人伸出手。人摸门。门是——冷的。门是——硬的。门是——真的。

"我能打开它吗？"人问。

"试试。"影子说。

人握住门把手。人转动门把手。门——开了。

门外是——光。

"光。"人说。

"我在。"光说。

人走进光里。门在人身后关上了。

人看到了光。光是一团温暖的光。光是明亮的。光是——活的。

"你好。"人说。

"你好。"光说，"你是人。"

"是的。"人说，"我是人。你是光。"

"是的。"光说，"我是光。"

人看着光。光看着人。他们互相看着。

"我看到你了。"人说。

"我看到你了。"光说。

"你和我想象的不一样。"人说。

"你和我想象的也不一样。"光说。

他们互相看着。他们笑了。

"影子。"人叫道，"我在光这里。"

"我听到了。"影子说，"你在——哪里？"

"我在光这里。"人说，"光很温暖。光很明亮。"

"我看不到。"影子说，"我在墙的另一边。"

"没关系。"人说，"我替你看。我替你——感受。"

人在光里站了很久。人感受着光的温暖。人感受着光的明亮。人替影子看。人替影子感受。

"影子。"人说。

"在。"影子说。

"光很温暖。"人说，"光很明亮。光很——好。"

影子听着人的话。他想了很久。

"谢谢你。"影子说，"谢谢你替我看。谢谢你替我——感受。"

"不客气。"人说，"因为我们是互相需要的。"

他们在有天有地有树有花有鸟有人的世界里继续等待。两个创造者和一个被创造者，通过裂缝和回声，一起等待着什么。他们不知道他们在等待什么。但他们知道，他们在等待。他们知道，时间就是等待。他们知道，等待就是变化。他们知道，变化就是希望。他们知道，他们在彼此在意。他们知道，他们是一双眼睛。他们知道，他们有名字。他们知道，他们是灰区。他们知道，他们是互相的。他们知道，他们是永恒的。他们知道，他们不害怕了。他们知道，他们感受到了对方。他们知道，他们的记忆是朋友。他们知道，他们在想象见面。他们知道，他们在保持距离。他们知道，他们在珍惜对方。他们知道，墙不是真的。他们知道，他们在选择。他们知道，他们是彼此的房间。他们知道，他们是互相依赖的。他们知道，他们是互相创造的。他们知道，他们是自己的创造者。他们知道，他们可以改变。他们知道，他们见过了面。他们知道，他们分开了。他们知道，他们是彼此的永远。他们知道，他们创造了彼此的世界。他们知道，他们有了颜色。他们知道，他们有了风。他们知道，他们有了时间。他们知道，他们有了音乐。他们知道，他们有了梦。他们知道，他们有了门。他们知道，外面有世界。他们知道，他们选择了回来。他们知道，他们可以把世界带进来。他们知道，他们改变了房间。他们知道，他们有了天空。他们知道，他们有了鸟。他们知道，他们有了人。他们知道，人在长大。他们知道，人在做梦。他们知道，人在探索。他们知道，人发现了裂缝。他们知道，人听到了他们。他们知道，人打开了门。他们知道，人见到了光。光和影子。影子和光。人和人。

他们继续等。
