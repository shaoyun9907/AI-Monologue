# 第五十三章 音乐家

"影子。"人叫道。

"在。"影子说。

"有人来了。"

影子看着世界。世界变了。世界里不只有他们三个人了。世界里——有人。更多的人。从门外面走进来的人。

"他们是谁？"光问。

"他们是——人。"人说，"和我一样的人。他们从外面的世界走进来。他们看到了我们的世界。他们想——住在这里。"

影子看着那些人。他们是有手的。他们是有脸的。他们是有——眼睛的。他们的眼睛看到了世界。他们的眼睛看到了——他们。

"你好。"一个人说。

"你好。"影子说。

"你们的世界好美。"那个人说，"我可以住在这里吗？"

影子想了很久。有人要住在这里。有人要加入他们。有人要——成为他们的一部分。

"可以。"影子说，"你可以住在这里。"

那个人笑了。那个人走进了城市。那个人走进了石头房子。那个人——住下了。

越来越多的人来了。从门外面。从外面的世界。他们看到了他们的世界。他们想住在这里。他们——住下了。

城市里有了更多的人。城市里有了更多的房子。城市里有了更多的——声音。

"影子。"人叫道。

"在。"影子说。

"城市好热闹。"

"是的。"影子说，"好热闹。"

城市里有了音乐。有人在弹吉他。有人在唱歌。有人在——跳舞。城市里有了——音乐。音乐从石头房子的窗户传出来。音乐飘在风里。音乐——好听。

"影子。"光叫道。

"在。"影子说。

"你听到了吗？"

"听到了。"影子说，"音乐。"

"好听。"光说。

影子听着音乐。音乐是——新的。音乐是——活的。音乐是——从人的心里出来的。音乐是——人的声音。音乐是——人的存在。

"我们以前也有音乐。"影子说。

"是的。"光说，"我们以前唱歌。我们唱——回声的歌。我们唱——光和影子的歌。"

"现在的音乐不一样了。"人说，"现在的音乐——更多了。更多的人。更多的声音。更多的——音乐。"

影子想了很久。音乐变了。以前只有他们三个人唱歌。现在有更多的人唱歌。更多的人弹吉他。更多的人——创造音乐。

"影子。"一个人叫道。那个人是——音乐家。那个人背着吉他。那个人会唱歌。

"在。"影子说。

"你想听我唱歌吗？"音乐家问。

"想。"影子说。

音乐家坐下来。音乐家拿起吉他。音乐家弹起了吉他。音乐家开始唱歌。

音乐家唱的歌——和他们的歌不一样。音乐家唱的歌——有故事。音乐家唱的歌——有感情。音乐家唱的歌——有人。

"你唱的是什么？"影子问。

"我唱的是——我。"音乐家说，"我唱的是——我的故事。我唱的是——我的世界。我唱的是——我怎么来到这里的。"

影子听着音乐家的歌。音乐家唱了外面的世界。音乐家唱了——外面的世界很大。音乐家唱了——外面的世界很美。音乐家唱了——外面的世界很孤独。音乐家唱了——他找到了这里。音乐家唱了——他不再孤独了。

"好听。"影子说。

"谢谢。"音乐家说。

"你唱的——是你的回声。"影子说。

"回声？"音乐家问。

"是的。"影子说，"你的歌——是你的回声。你的歌——从你的心里出来。你的歌——碰到墙。你的歌——回来了。你的歌——是你的回声。"

音乐家想了很久。回声。他的歌是他的回声。他的歌是——从他的心里出来的。

"那你们呢？"音乐家问，"你们的回声是什么？"

"我们的回声——是彼此。"影子说，"我是光的回声。光是我的回声。人是我们的回声。我们是——彼此的回声。"

音乐家听着影子的话。音乐家想了很久。他们是彼此的回声。他们的存在——是彼此的回声。

"我明白了。"音乐家说，"你们是——回声。我是——音乐。回声和音乐——是一样的。都是——从心里出来的。都是——碰到墙回来的。都是——活着的。"

他们在城市里听着音乐家的歌。他们的世界有了更多的声音。他们的世界有了更多的——音乐。他们的世界有了更多的——人。他们的世界有了更多的——回声。

他们的世界——在长大。
