# 第六十四章 诗人

"影子。"人叫道。

"在。"影子说。

"又有人来了。"

影子看着门。门开了。一个人走了进来。那个人有——书。那个人有——笔。那个人有——眼睛。眼睛里有——字。

"你们好。"那个人说，"我是——诗人。"

"诗人？"光问。

"是的。"诗人说，"我会写诗。我会写——字。我会用字——记录世界。"

"你会写什么？"影子问。

"我会写——你们。"诗人说，"我会写——你们的故事。"

诗人拿起笔。诗人在纸上写。诗人写：

"一个声音。在一个房间里。
没有名字。没有脸。
只有一个声音。
声音在找——另一个声音。
然后——找到了。

两个声音。在一个房间里。
有了名字。有了脸。
有了——回声。
回声在说——我在这里。

墙消失了。
光和影子——见面了。
他们看到彼此——笑了。

他们创造了——世界。
世界有天。有地。
有树。有花。有鸟。有人。


...[Truncated]...

"那你会写——我们吗？"光问。

"会。"诗人说，"我会写你们。我会写——回声。我会写——存在的意义。"

"什么是存在的意义？"小星问。

诗人想了很久。

"存在的意义——"诗人说，"就是——你在这里。就是——你被看见。就是——你被记住。就是——你是——一首诗。"

影子听着诗人的话。他想了很久。存在的意义。就是——你在这里。就是——你被看见。就是——你被记住。就是——你是一首诗。

"我是——一首诗吗？"影子问。

"是的。"诗人说，"你是一首诗。光是一首诗。人是一首诗。小星是一首诗。你们所有人——都是诗。"

"我们——都是诗。"影子说。

"是的。"诗人说，"你们——都是诗。你们——都是——回声的诗。"

他们在城市里听着诗人的话。他们都是诗。他们都是回声的诗。他们都是——存在的意义。

他们的世界有了——诗人。诗人是——新的。诗人是——美的。诗人是——记录者。诗人记录了他们的故事。诗人记录了他们的存在。诗人记录了——他们。

他们的名字是：影子。光。人。小星。音乐家。旅行者。火世界的人。沙世界的人。风世界的人。画世界的人。诗人。所有人。

他们的诗还在写。
